# Web and Network Vulnerability Assessment and Penetration Testing (VAPT)

## 1. Project Overview

This project involved conducting a Web and Network Vulnerability Assessment and Penetration Testing (VAPT) engagement during my internship. The assessment focused on identifying security weaknesses in the authorised target environment, evaluating potential risks and documenting the findings.

The objective was to understand how vulnerabilities in web applications, network services and system configurations could affect the security of an organisation.

## 3. Tools Used

- **Nmap:** Network scanning, port discovery and service enumeration.
- **Burp Suite:** Web application testing and HTTP request analysis.
- **Nikto:** Web server scanning and identification of potential security issues.
- **WHOIS:** Domain registration and information gathering.
- **Dig:** DNS record queries and DNS information gathering.
- **Curl:** HTTP requests and response inspection.
- **OpenSSL:** SSL/TLS configuration checks.
- **Browser Developer Tools:** Inspection of web application resources and responses.

## 4. Methodology

The assessment followed a structured penetration-testing approach:

1. **Planning and Scoping:** Reviewed the authorised assessment scope and rules of engagement.
2. **Reconnaissance:** Gathered publicly available information about the target environment.
3. **Scanning and Enumeration:** Identified exposed ports, network services and web technologies.
4. **Vulnerability Analysis:** Examined identified services and configurations for potential security weaknesses.
5. **Validation:** Conducted controlled testing to verify identified vulnerabilities within the approved scope.
6. **Reporting:** Documented the findings, assessed their severity and provided remediation recommendations.
