# Web and Network Vulnerability Assessment and Penetration Testing (VAPT)

## 1. Project Overview

During my internship in 2025, I had the opportunity to take part in a Web and Network Vulnerability Assessment and Penetration Testing (VAPT) engagement. The purpose of the assessment was to identify security weaknesses in the authorised target environment, understand the risks they could pose and document the findings.

This experience gave me a better understanding of how vulnerabilities in web applications, network services and system configurations can affect an organisation's security.

## 3. Tools Used

The following tools were used during different stages of the assessment:

- **Nmap:** Used to scan the network, identify open ports and discover running services.
- **Burp Suite:** Used to test web applications and inspect HTTP requests and responses.
- **Nikto:** Used to check web servers for potential security issues.
- **WHOIS:** Used to gather domain registration information.
- **Dig:** Used to query DNS records and gather DNS information.
- **Curl:** Used to send HTTP requests and examine server responses.
- **OpenSSL:** Used to check SSL/TLS configurations.
- **Browser Developer Tools:** Used to inspect web application resources and responses.

## 4. Methodology

The assessment was carried out in several stages:

1. **Planning and Scoping:** Reviewed the approved testing scope and the rules that had to be followed during the assessment.
2. **Reconnaissance:** Collected publicly available information about the target environment.
3. **Scanning and Enumeration:** Used scanning tools to identify open ports, running services and web technologies.
4. **Vulnerability Analysis:** Reviewed the identified services and configurations to look for possible security weaknesses.
5. **Validation:** Performed controlled tests to check whether the identified vulnerabilities could be confirmed.
6. **Reporting:** Recorded the findings, assigned severity levels and included recommendations to address the identified issues.

## 6. Key Learning Outcomes

This internship gave me the opportunity to apply some of my cybersecurity knowledge in a practical setting. Throughout the assessment, I gained experience in:

- Gathering information about a target environment through reconnaissance.
- Identifying open ports, running services and possible security weaknesses.
- Using tools such as Nmap, Burp Suite and Nikto during security testing.
- Examining web applications and network service configurations.
- Checking and validating potential vulnerabilities within the approved scope.
- Understanding vulnerability severity and suggesting possible ways to address security issues.
- Preparing a VAPT report with technical findings, business impact, remediation recommendations and prioritised actions.

One of the main things I learned was how the different stages of a VAPT engagement fit together. I also gained a better understanding of the importance of documenting findings clearly so that organisations can understand the risks and take steps to address them.

## 7. Areas for Improvement

One thing I would improve in future assessments is how I store testing evidence. In this project, I mainly used screenshots to document the tool outputs. In future, I would also keep sanitised copies of raw logs where permitted, so I can refer back to the original results more easily.

I would also like to continue developing my vulnerability analysis and testing skills, especially when dealing with more complex security issues. This project gave me practical experience with the VAPT process and helped me identify areas where I can continue improving as a penetration tester.
